# 常见问题

## 授权与接口

### 提示“未授权”或要求输入访问码

站点配置了访问码（`CODE`）。在授权页或"设置"中填入访问码即可。也可以填写自己的 API Key，前提是站点没有设置 `HIDE_USER_API_KEY`。

### 使用自定义接口或插件时返回 401，提示需要访问码

自定义接口和插件的请求经本站代理转发。站点开启访问码时，转发到自定义地址必须带有效访问码；只填 Key 不够。请在设置中同时填写访问码和该接口的 Key。

### 填了自定义接口，但上游提示缺少或错误的 API Key

服务端的 API Key 永远不会发给自定义地址。使用自定义接口时，需要在设置里填写你在该接口上的 Key。

### RAGFlow 请求报错或没有响应

服务端需要配置 `RAGFLOW_URL`（通常还需要 `RAGFLOW_API_KEY`）。没有配置 `RAGFLOW_URL` 时，`/api/ragflow` 会直接返回 400；RAGFlow 也不会使用主 API Key。

## 对话

### 回复显示错误而不是内容，这些提示是什么意思？

回复失败时，消息里会显示一段 `{"error": true, "message": ...}`，message 是具体原因：

| 提示 | 含义与处理 |
| --- | --- |
| 上游返回的错误原文（如 overloaded、quota） | 上游服务出错，按提示处理，或稍后重试 |
| 上游请求失败（HTTP 4xx/5xx） | 鉴权、额度或上游网关问题，括号里附有上游返回的说明 |
| 模型没有生成正文：输出达到长度上限 | 推理过程耗尽了输出额度。可以简化问题、减少附带的历史，或换用其他模型 |
| 上游返回了空回复（finish_reason: …） | 上游正常结束但没有返回内容，例如被内容过滤 |
| 请求超时：上游在 N 秒内没有开始响应 | 上游过慢或网络不通 |
| response interrupted | 页面刷新或关闭时，这条回复还没生成完 |

### 回复中有可折叠的“思考”内容

这是推理模型返回的推理过程。它只用于展示，下一轮对话时不会再发回给模型。

### 会话标题没有自动生成

标题在对话达到一定长度后才生成，并且需要用于总结的模型能正常返回文本。也可以在对话中使用“刷新标题”重新生成，或手动重命名。

### 为什么附带的图片发不出去？

当前模型不支持图片，或者图片数量超过了该模型的上限。请换用支持图片的模型，或移除部分图片。管理员可以用 `VISION_MODELS` 把模型标记为支持图片。

## 数据

### 聊天记录保存在哪里？

保存在浏览器本地（IndexedDB），不会上传到本站服务端。清除站点数据或更换浏览器后，记录就不在了。需要多设备共用时，可以使用"设置 → 同步"（WebDAV 或 Upstash，见[使用指南](./user-guide.md#7-数据存储与同步)）。

### 遇到 “Loading CSS chunk … failed” 或页面空白

通常是站点刚重新部署，浏览器还在使用旧的页面资源。强制刷新页面即可。

## 部署

### 修改环境变量后没有生效

在 Vercel 上修改环境变量后，需要重新部署（Deployments → Redeploy）才会生效。

### 回复很慢，或长请求被中断

Vercel Edge 函数必须在 25 秒内开始返回响应，流式回复开始之后则可以持续更长时间。图片生成走 Node 运行时，有更长的时限。如果上游首个响应经常超过 25 秒，可以考虑换更快的上游，或使用 Docker 自托管。
