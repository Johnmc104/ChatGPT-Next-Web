# 上游残留与文档清理

## 1. 背景

`plan/17` 修正了部署入口，但仓库里仍有大量从上游继承的文档和模板。它们描述的是上游项目，而不是本仓库：

- 上游 FAQ 和用户手册；
- 翻译指南；
- GPT 时期的早期分析文档（`docs/archive/`）；
- 双语 Issue/PR 模板，部署方式选项里还有"官方安装包、Zeabur、Sealos"；
- 上游的行为准则。

用户确认可以删除或重写这些内容（2026-11-13）。

## 2. 原则

- 文档只描述本仓库当前的行为。旧文档的历史版本保留在 git 历史中，不再单独归档。
- 用户文档只写中文，合并成两份：使用指南和 FAQ，并与 README 互相链接。
- 以下三类上游内容保留：
  - `LICENSE` 中的上游版权声明（MIT 许可要求保留）；
  - README 中注明分叉来源的一句话；
  - 插件页指向第三方插件目录 `NextChat-Awesome-Plugins` 的链接。它是外部资源，不是残留。
- 以下内部标识不改：`STORAGE_KEY`、Service Worker 缓存名中的 `chatgpt-next-web`。改名会让已有用户的本地数据和缓存失效。
