# 自定义接口配置与诊断计划

## 1. 功能边界

“自定义接口”只描述请求去哪里以及如何认证：Provider 类型、Endpoint、API Key、Azure deployment/API version、代理和请求协议。它不负责增加模型名称，也不改变模型能力。接口配置可以使用 OpenAI-compatible、Azure、RAGFlow 或未来的独立 adapter。

## 2. 现状问题

当前 `ProviderConfigSection` 将开关、Provider、Endpoint 和 Key 混在一个列表中；Endpoint 只做字符串保存，用户无法在保存前知道 URL 是否可达、路径是否包含 `/v1`、认证方式是否正确。错误通常在真正发送聊天请求后才显示。URL 分享命令也只支持 `key` 和 `url` 两个字段，没有版本校验或敏感字段确认。

## 3. 目标设计

定义 `CustomEndpointConfig`：

```ts
interface CustomEndpointConfig {
  id: string;
  provider: "openai-compatible" | "azure" | "ragflow";
  baseUrl: string;
  apiKeyRef?: string;
  apiVersion?: string;
  deployment?: string;
  enabled: boolean;
}
```

设置 UI 分为“基本连接”“认证”“协议参数”“连接测试”四段。连接测试只调用模型列表或轻量 health endpoint，结果包含 HTTP 状态、响应耗时、认证失败和路径错误；日志只记录 host、状态码和耗时，不记录 Key 或完整 URL query。

## 6. E4 设置链接导入（2026-11-05，已实现并定向验证）

- 抽取 `app/domain/settings/link.ts`：接受 `version: 1` 和旧版无版本 payload，校验 `url`、`key`、`provider`、`customModels`、`defaultModel`，拒绝未知版本、未知字段和非法类型。
- 确认框隐藏完整密钥以及 URL query/fragment，说明覆盖范围；错误仅显示分类文案，不回显原始链接。访问码也不再记录日志或明文预览。
- 确认后按 Provider 写入对应接口字段；仅导入模型时不启用或切换自定义接口。默认模型更新全局配置，显式自定义 ID 优先于内置别名。
- URL 命令消费采用快照遍历和 history replace，避免相邻参数被跳过或敏感链接继续保留在当前历史项；同一路由在 StrictMode 下只消费一次，关闭确认框按取消结束。等待服务配置返回后再读取 `disableFastLink`，避免首次加载绕过禁用设置。
- 新增解析、应用和 URL 命令测试。Node 22.16.0 下 4 个文件、26 个用例全部通过；lint 通过（现存图片 hook 警告 1 项），`git diff --check` 通过。全套 24 个测试文件中 23 个通过，消息提取 4 个用例失败；TypeScript 检查有多模态和旧测试类型错误，下一阶段优先处理，未标记整体构建通过。

示例：`/?settings=` 后附 `encodeURIComponent(JSON.stringify({version:1, customModels:"deployment-a@OpenAI=工作模型", defaultModel:"deployment-a"}))`。接口链接可另含 `provider:"OpenAI"` 和 `url:"https://gateway.example/v1"`；不要公开分享带 Key 的链接。
