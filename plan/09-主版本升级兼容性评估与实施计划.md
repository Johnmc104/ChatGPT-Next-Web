# 主版本升级兼容性评估与实施计划

## 1. 目标

在保持 Node 18.17–22.x、Web、Tauri、Edge route、SSE 和图片链路可用的前提下，分阶段评估并实施主版本升级。每个小阶段单独验证、更新本计划并提交 Git，避免依赖变更和业务修复混在一个提交中。

## 2. 当前基线与候选

当前基线为 Next 14.2.35、React 18.3.1、TypeScript 5.2.2、Tauri CLI 1.5.11、Zod 3.24.1、Zustand 4.5.7。候选主版本包括 Next 16.x、Tauri CLI 2.x、ESLint 9/10、TypeScript 7、Zod 4、Zustand 5、React Markdown 10 和 React Router 7；Node 26 作为当前长期目标。

## 3. 实施阶段

- M0：记录候选版本、Node/peer 要求、Next 迁移点和回退边界。
- M1：升级到主流 Next 16.4.5、React 19.3.1 及配套 `@next/*`、类型包和 ESLint 10，迁移 flat config 与 `next build --webpack`，验证 lint、TypeScript、Jest、生产构建、Edge route、SSE 和图片 payload。
- M2：在阶段内集中修复升级暴露的运行时或类型兼容问题，补充回归测试，阶段完成后一次提交。
- M3：评估 Tauri 2、TypeScript 7、Zod 4 等独立主版本；若需要配置或 API 重构，建立独立提交和回退点。
- M4：Next 16 后续版本、Node 27+ 与 React 19 后续版本只在 M1/M2 稳定后评估，不能和 Tauri/TypeScript/Zod 同批升级。

## 4. 验收标准

每个阶段必须记录实际版本、失败尝试及回退原因；`yarn lint`、`yarn test:ci`、`yarn build` 通过，且现有模型选择、首次授权、自定义接口/模型、图片上传/预览和流式响应测试无回归。

## 5. 阶段记录

- M0（2026-11-06，已完成）：确认 Next 16.4.5 要求 Node `>=20.9.0`，ESLint 10 要求 Node 20.19/22.13/24；Node 26 作为长期目标保留在后续验证。Tauri 2、TypeScript 7、Zod 4、Zustand 5 等列为独立风险项。
- M1（2026-11-06，已完成）：升级到 Next 16.4.5、React 19.3.1、ESLint 10，迁移 flat config、React 19 类型、异步 route params 和 `next build --webpack`；同步升级 `@hello-pangea/dnd` 到 18.0.1，补充 IndexedDB SSR 能力判断，删除旧 `.eslintrc.json`/`.eslintignore`。Node 24 与 Node 26 Bookworm 容器中 lint、TypeScript、Jest 39/344 和生产构建均通过；Node 26 使用 `YARN_IGNORE_ENGINES=1` 进行基线验证后已纳入 engines、`.nvmrc`、`ensure-node.sh` 与 Dockerfile。构建仍有 Edge/preferredRegion 弃用提示，作为后续迁移项。
